# Avatar Landing Page

I built this landing page inspired by the Avatar movie to practice HTML and CSS. I wanted to learn how to build a full-screen hero section with a navigation bar and a background image.

> Note: The background images are from the Avatar movie. I used them for learning purposes only.

## Live Demo
[View the website](https://youssef231120.github.io/youssef-avatar/)

## What I Built
- A navigation bar with links (home, about, contact, login, photos)
- A hero section with a title, a short description, and a login button
- A full-screen background image with a dark overlay

## Tools I Used
- HTML5
- CSS3

## What's Next
Right now the page is designed for desktop screens. I'm currently learning responsive design, and my next step is to make this page work on tablets and phones.
